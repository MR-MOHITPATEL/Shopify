# ZenJeevani Shopify Theme

A modern, minimal Shopify theme developed for a nutraceutical e-commerce store. This theme is designed with a focus on conversion optimization and premium aesthetics, inspired by the Forma Health UI.

## Features

- **Modern Minimalist Design**: A clean aesthetic with a sophisticated color palette (Forest Green, Sage, and Neutrals).
- **Responsive Layout**: Mobile-first design for a seamless shopping experience.
- **Shopify 2.0 Ready**: Built with modular JSON templates and Liquid sections.
- **Key Sections Included**:
  - Custom Hero Banner with faded typography.
  - Featured Product Grid.
  - Doctor/Expert Trust Section.
  - Accordion FAQ.
  - Comprehensive Footer.
  - Specialized Product Detail Page with Ingredients and Benefits.

## Folder Structure

- `assets/`: Theme styles (CSS) and Javascript.
- `layout/`: Main theme layout files.
- `sections/`: Reusable Liquid sections.
- `snippets/`: Small Liquid snippets.
- `templates/`: JSON and Liquid templates for pages and products.

## Development

This theme was built using the Shopify CLI. To preview changes locally, use:

```bash
npx shopify theme dev --store=your-store.myshopify.com
```
